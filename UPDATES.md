# Updates for Newer Software Versions

Server software moves faster than any LTS release. This page records changes since the book went to press: new versions, renamed packages, and commands whose behavior has changed. The procedures and the reasoning in the book still apply; use this page to adjust version numbers and package names.

Each update was verified on Ubuntu Server 26.04 LTS before it was listed here.
